# 山河问剑录 · 3.6 设计稿 —— 师承与门派恩仇

> 状态：**草稿，待公子裁定**
> 公子口述定调：拜师不锁死在门派里——门派能拜，散人 NPC 也能拜；门派之间有竞争、有合作，走玄幻小说那套活的关系网。

---

## 一、定盘星

1. **师父是一个人，不是一张入派登记表。** 拜的是某位有名有姓有性情的 NPC，不是"青云剑宗"这四个字。
2. **两条路都能走通**：宗门拜师（入派配师）与散人拜师（叶孤鸿、姜暮寒这类无门无派的高人）皆可；师承带来的恩怨、人脉、传承，比门派招牌更贴身。
3. **门派是活的江湖**：五宗之间两两有关系——有世仇、有盟好、有生意往来；宗门大比、秘境争夺、联手剿魔轮番上演，玩家站进去就被推着走。
4. **背叛有代价**：玄幻小说的规矩——叛师者人人喊打；改投他门可以，但旧账得还。

## 三、师承核（新增 `systems/master.js`）

### 3.1 谁能为人师

- **宗门师父**：拜入宗门时，按玩家主修路线（攻/丹/体/阵/商）自动配发一位本宗高阶 NPC 为师（如青云剑宗 → 沈青崖/洛雪衣）。
- **散人师父**：NPC 满足以下条件即"可拜"：境界 ≥ 玩家+1 且有一技之长（`talent≥3`）。池子现成：姜暮寒（符）、白玉京（阵）、叶孤鸿（刀）、谢惊鸿（盗术）、陆吾（体修）、苏白（文心）、云无月（魔功，高风险高回报）。
- 门派弟子拜散人师父 = **兼师**，需本宗默许（好感足够则无碍；过低触发"门中非议"，贡献获取打折）。

### 3.2 拜师三关（散人路线的仪式感）

1. **递帖**：好感 ≥ 阈值（按性情浮动：孤傲者 70，豪爽者 50，古怪者另配考验）。
2. **考验**：师父按其道给一道题——叶孤鸿要你接他三刀、姜暮寒要你画符过关、云无月让你办一件"不该问的事"。考验走现有战斗/制作/奇遇系统，不另造轮子。
3. **奉礼**：拜师礼（灵石或应景之物；穷有穷拜法——苏白只认心诚）。

### 3.3 师徒账本（数据结构）

```js
p.master = {
  npcId: 'n9',            // 师父
  bond: 40,               // 敬师值 0~100，决定教导质量与态度台词
  gifts: [],              // 师赐之物（死后入往世簿的"旧物"伏笔）
  joinedDay: 100,
  lessons: { gongfa: 0, craft: 0 }, // 受教次数（可加成次数上限）
}
```

### 3.4 教导五事（师父每天能给你什么）

| 五事 | 效果 | 频率 |
|---|---|---|
| **传功** | 解锁/加速师父专属功法（按境界解锁，`bond` 越高传得越快） | 境界节点 |
| **指路** | 发"师命"任务（复用 sect 任务产线，报酬加 `bond` 不加贡献） | 数日一桩 |
| **护道** | 战败濒死时师父出手相救（每次消耗大量 `bond`，一天一次） | 救命绳 |
| **赐宝** | 论道/生辰/立功时赐物（从师父本行出：符师给符、刀客给刀） | 随机 |
| **传艺** | 炼丹/炼器/制符/参悟成功率 +X%（按师父本行，受 `bond` 影响） | 被动 |

### 3.5 师父是活人（恩仇核联动）

- **师父有仇家**：karma 里预埋师门恩怨——拜入后仇家偶尔寻上门（战斗/抉择事件），办了涨 `bond`，躲了掉。
- **师父会云游**：数日不在，师命挂起——留一张手书。
- **师父会死**：高龄低寿NPC有生老病死的日程；师父身陨触发**衣钵事件**（大遗产+一段戏），并继承其仇家——玄幻味最浓的一口。

## 四、门派关系核（扩展 `world.js` + `sect.js`）

### 4.1 两两关系矩阵

五宗两两共 10 组关系，存 `p.world.sectRel = { 'qingyun|danxia': 40, ... }`（-100 世仇 ~ +100 同盟），五档：

| 档位 | 区间 | 表现 |
|---|---|---|
| 世仇 | ≤ -60 | 敌对借刀杀人频发；弟子在双方地盘相遇即战 |
| 敌视 | -60~-20 | 任务里互泼脏水；坊市互相抬价 |
| 平淡 | -20~20 | 井水不犯河水 |
| 友好 | 20~60 | 坊市互惠折扣；联袂任务可接 |
| 同盟 | ≥ 60 | 联手剿魔大事件；弟子互访论道 |

初始关系按世界观预设：青云×丹霞友好、青云×磐岩互敬、万宝×人人有生意、周天×磐岩淡漠……（写死一组初始值）

### 4.2 关系怎么动（玩家是变量之一）

- **玩家的手**：杀别派弟子 → 该派与你的私怨 + 该派对玩家的观感恶化（间接拖累两宗关系口径）；护送/赠药/完成他派委托 → 回暖。
- **天下的大手**：每旬（游戏日滚动）世界自动推演一次——世仇宗门摩擦掉点，同盟互通涨点，随机小事件（争夺矿脉、弟子比剑）写进《行路志》。
- **宗门大战**：关系跌破 -60 且触发事件 → 开战（复用 `warActive` 全套）；打完按胜负重设关系值。

### 4.3 三桩大事件（关系值的具象戏）

1. **宗门大比**（友好/平淡期皆可触发）：玩家可代表本宗出战，按名次得奖励+关系微调；赢了敌对宗门的天才，对方记仇（karma）。
2. **秘境争夺**（敌视期）：某秘境（接 dungeon.js）两宗同日开启，玩家护旗/夺宝/谈判三选。
3. **联手剿魔**（同盟期）：跨宗联合任务链，报酬丰厚，敌我 NPC 同队出阵。

## 四之二、门派众生层（回应"大宗门数万人"的体量感）

单靠手写 NPC 撑不起大宗门的气象，按**三层人口**来：

### 第一层 · 名宿层（手写，深）
- 现有 14 人全保留，另为五宗各补 3~5 位**有名有姓有戏**的：掌门/首席/护法/老祖各司其职（如青云剑宗补：掌门玄真子、执法堂主、藏经阁守阁人）。
- 五宗合计约 25~35 位，全部参与师承/恩仇/大事件的正面戏份。

### 第二层 · 同门层（种子生成，广而浅）
- 每宗生成 **60 名同门弟子**（五宗 300 人），字段：姓名（按宗门气质的姓池+名池组合：青云用「叶/林/楚+剑霜鸿远」，丹霞用「苏/白/温+兰芷芸香」）、所属职位、境界（金字塔分布：练气多、金丹少）、性情一句签、恩仇值。
- **同种子同命**（设计口径铁律）：名字与名单由存档种子决定，读档不漂移。
- 用途：宗门大比的对手段位池（打到镜面同门才遇名宿层）、同门互助/借贷/眼红事件、**杀一个同门是有后果的**——对方宗门关系掉点、其"同门师兄"记仇进 karma。
- 拜师后自动分到一位**引荐师兄**（从同门层抽）：新人引导戏 + 请教功能（聊八卦/问功法提示）。

### 第三层 · 门面层（纯数字气象）
- 每宗一个"门中气象"数据：`门下弟子三千，执事三百，供奉十二`——不参与机制，但写进山门光景句、大比开场白、名册页，给足"数万人"的排面。

### 交互口子
| 场景 | 名宿层 | 同门层 | 门面层 |
|---|---|---|---|
| 拜师/师承五事 | ✅ 主体 | 引荐师兄（请教/传闲话） | — |
| 宗门大比 | 决赛圈对手 | 分组赛对手池 | 看台欢呼/开场白 |
| 恩仇记录 | 深戏份 | 记仇/寻仇（浅但真发生） | — |
| 地图节点驻守 | 城市主NPC | 随机遇同门（"原来是本门师妹"） | 山门气象句 |

## 五、叛师与改投

- **叛师**（主动）：`bond` 清零、恩仇账记"欺师灭祖"、本宗声望崩、师父亲自来问罪（硬仗，打赢可脱门籍但天下皆知）。遁走他派：接纳方要求更高贡献入门，且部分正派拒收叛徒。
- **师徒恩断**（被动）：连累师门/大恶之事 → 师父逐你出户，效果同叛但少一段追杀。
- **另拜散师**：原师父若在世且 `bond` 高，可"同参二师"（限定其一为散师）；若因叛离，永不复见。
