# 设计 3.7 · 系统咬合 —— 让每个系统都承重

> 针对反馈：「任务是任务，修炼是修炼，装备、丹药、符箓、技能那些没用到，只一直点击修炼就可以到最顶级，每个功能没有一点点关联性。」
>
> 设计原则（一句话）：**修炼的产出不变，但在"突破、渡劫、战斗"三个必经关口设卡，每一张卡都指定用其他系统的产物来解。** 不做砍产出式的惩罚，做"过关需要执物"式的咬合。

## 一、病根诊断

现状：修为是唯一主线货币，闭关点击线性推层级；丹药/符箓/装备/功法只提供面板加成（可买可不买），主线全程可以绕开它们。于是各系统成了"平行小卖部"，不是"同一条路的不同段"。

## 二、五道咬合卡（按修为主线顺序）

### 卡1 · 瓶颈：闭关收益递减 + 修为溢出上限
- 同一层内连续闭关，收益逐次衰减（如 100%→80%→65%→50%→50%…），层次越高衰减越早。
- 无「破境机缘」时修为囤积设软上限（如当层需求的 130%），超出部分不再增长。
- **效果**：纯点击修炼会"卡"在每层，必须出门找机缘。
- 破境机缘来源：奇遇、师命论道、红尘历练——把玩家推向江湖系统。

### 卡2 · 突破要丹（丹药 ← 采集/坊市/炼丹）
- 大境界突破（炼气→筑基→金丹…）消耗对应境界的「破境丹」（新增丹药线：破境一~九转）。
- 破境丹只能炼丹产出：药材来自采集/坊市/秘境掉落（药材体系已存在，炼丹炉已有 T15）。
- 丹成品率受丹道熟练度影响 → 炼丹成为可养成副业。
- **效果**：不碰炼丹系统，主线推不动大境界。

### 卡3 · 渡劫用符（符箓 → 天劫）
- 渡劫三策保留；新增第四项「符护」：渡劫前可贴符（每张改成功率/护住根基，一次消耗）。
- 符箓由画符产出（符坊已有 T16），高阶符需要高阶符纸（坊市/掉落）。
- 渡劫失败仍走「回溯因果」，但贴过符可减少折损——符箓是"保险"，不是必需，但性价比明显。
- **效果**：符箓从"战斗可选品"变成"命关消耗品"。

### 卡4 · 战斗掉材 → 锻造装备（装备 ← 战斗/锻造）
- 精英/头目稳定掉落「玄铁/妖骨/灵纹布」等锻造材料（材料体系已有）。
- 装备新增耐久：战斗磨损，久战必换 → 锻造/购买成为持续需求。
- 高阶装备配方来自师父传艺/门派贡献 → 与师承、宗门咬合。
- **效果**：战斗不再是刷数字，而是装备线的资源入口；装备从"一次性面板"变成"养成线"。

### 卡5 · 功法参悟（技能 ← 感悟/论道）
- 功法不止面板加成：每部功法可「参悟」升阶（1~3 阶），消耗感悟值（insight 已有）+ 灵石。
- 功法阶数影响修炼效率与招式威力（战斗技能伤害按功法阶数缩放）。
- 论道（师承已有）、奇遇、闭关顿悟给感悟 → 技能与修炼互为因果。
- **效果**：功法从"买了就完"变成"长线投入"，且直接影响修炼速度。

## 三、顺带咬合（不改核心，只加钩子）

- 师命复命奖励改为「灵石 + 破境丹药材/符纸」随机——师承直接喂主线卡2/卡3（3.6a 已具雏形）。
- 拍卖行定期上架破境丹/高阶符纸——灵石消耗端多一个去口，财路系统有价值。
- 灵兽喂养材料 = 锻造药材同源——不新增系统，只共用材料。

## 四、分期落地

| 期 | 内容 | 验收（四闸） |
|---|---|---|
| 3.7a 最小闭环 | 卡1 瓶颈递减 + 卡2 突破要丹 + 师命奖励喂丹 | 纯点击修炼在筑基前必卡；炼一炉破境丹可破境；探针 T 系全绿 |
| 3.7b | 卡3 渡劫用符 + 卡5 功法参悟 | 渡劫贴符探针；参悟探针；回归 59 项零失败 |
| 3.7c | 卡4 装备耐久/锻造 + 拍卖上架 | 耐久磨损→锻造闭环探针；经济曲线盘点 |

## 五、数值底线（自设约束）

- 突破丹的炼制成本 ≈ 同境界 1~2 天产出的灵石/药材，让"卡"是节奏不是堵墙。
- 收益递减只对"无脑重复闭关"生效，论道/奇遇/历练获取修为不受衰减。
- 所有新卡均可用多条路径解（炼丹 / 拍卖买 / 师赐 / 奇遇拾），不锁死单一路线。
