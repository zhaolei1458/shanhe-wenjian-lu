# 3.5 设计稿（修订版）：六系增强 + 奇遇/挖宝双通道

> 对应指令：「增强装备系统，宠物系统，技能系统，支持奇遇，挖宝等方式获得」「还有增强法宝系统，丹药系统」
> 公子定夺：**符箓不删，保留并增强**；挖宝**随处可挖**（不需地域匹配）。

## 〇、总原则

1. 零依赖 vanilla JS 不变，`scripts/modules.json` 构建管线不动，新模块按序挂入。
2. 一切新物品统一进 `GameData.ITEMS` 注册表，以 `type` 字段区分（现有：pill/talisman/gongfa/artifact/material；新增：map 藏宝图、egg 兽蛋）。
3. 获取通道统一规划：
   - **奇遇**（历练随机事件，免费看脸，中低档为主）
   - **挖宝**（藏宝图消耗品驱动，中高档主出口）
   - 黑市/拍卖行/秘境/荒洞/NPC 售货（少量露出稀有品）
   - 坊市商城只卖基础品与藏宝图，不卖顶级稀有品
4. 每个分段独立可验（build + verify + bot 冒烟），分段提交。

## 一、挖宝玩法（新增，本次核心）

### 藏宝图道具（新 type: 'map'）
| id | 名 | 档 digTier | 参考价 | 说明 |
|---|---|---|---|---|
| map_cangbao | 残破藏宝图 | 1 | 200 | 前人埋藏，所得以材料和灵石为主 |
| map_gu | 古修遗图 | 2 | 900 | 古修洞府遗藏，可出词缀装备/功法/兽蛋 |
| map_xian | 仙家残图 | 3 | 3000 | 仙家遗宝，可出独名法宝/高阶功法/古兽蛋 |

### 机制（随处可挖版）
1. 新模块 `js/systems/dig.js`（DigSys），注册进 modules.json；背包藏宝图出现「寻宝」动作（act-dig，复用 act-use 通道）：
   - 使用一张图 → 按 digTier 查 `GameData.TREASURE_POOL` 随机结算：
     - 高概率（~55%）：灵石、材料、丹药、兽粮
     - 中概率（~35%）：带词缀装备、功法/功法残页、兽蛋、符箓（中阶）
     - 低概率（~10%）：高阶功法、独名法宝、仙品丹药
     - 负面彩蛋（~8% 独立判定）：挖空（叙事文案）或惊动守宝妖兽（转入战斗，战胜掉落翻倍）
   - 三档图各有独立叙事文案组，挖宝本身即是看故事。
2. 图获取通道：坊市杂货、黑市 POOL、拍卖行 LOT_POOL、秘境 gain、荒洞 treasury、奇遇「古修遗藏」、高 tier 妖兽 rareDrop。

## 二、符箓系统增强（保留并增强）

1. **新符箓 6-8 张**，补齐现有 fkind 之外的玩法：
   - 疗伤符（新 fkind 'heal'：回复自身气血）
   - 蚀毒符（新 fkind 'poison'：中毒，每回合按上限百分比掉血，持续 3 回合）
   - 玄壁符（新 fkind 'reflect'：反伤护壁，受击反弹三成伤害）
   - 煞影符（高阶 damage，5.5 倍攻）
   - 天雷符（最高阶 damage，6.5 倍攻 + 概率麻痹一回合）
2. **battle.js** 新增 heal/poison/reflect 三种 fkind 结算分支；符修六境加成（雷笔境/追雷境）对新 damage 符同享。
3. **画符营生**：drawTalisman 产出池按 type==='talisman' 自动纳入新符（若为硬编码名单则改为动态取 ITEMS 中全部 talisman），高境界画符可出新高阶符。
4. **来源**：挖宝出中高阶符；奇遇「符师遗府」出符与朱砂；黑市/拍卖露出。

## 三、奇遇扩充（explore.js EventSys）

新增 8-9 桩，与六系一一对应，支持境界分层：

1. **前辈遗府**——坍塌洞府，得带词缀装备（装备线）
2. **荒山药圃**——野化灵药丛生，得灵药/丹方残页（丹药线）
3. **兽穴救崽**——得兽蛋或低忠诚幼兽（宠物线）
4. **剑冢**——得高 grade 武器（装备线）
5. **断碑残功**——得功法残页或完整功法（技能线）
6. **古修遗藏**——枯骨手中半张图，得藏宝图（挖宝线，兼教学）
7. **法宝残魄**——器灵低语，得独名法宝或祭炼材料（法宝线）
8. **符师遗府**——符案朱砂犹润，得符箓/画符材料（符箓线）
9. **丹炉遗火**——废丹炉炉火未熄，得稀有丹药（丹药线）

每桩带 minRealm 门槛与 2-3 层结果分支。支线新增「掘藏人的遗产」（quest.js SIDES）：串起藏宝图获取→挖掘→寻得先人遗泽的教学叙事，奖励仙家残图一张。

## 四、装备系统增强

1. **词缀池扩充**：BALANCE.AFFIXES 新增 6-8 条——吸血、反伤、破防、会心伤害、灵力回复、击杀回蓝、受击减伤、连击。挂载/渲染管线（rollAffixes/affixBonus/affixText）不动，纯数据扩展。
2. **新套装 2 套**：玄龟套（防御向）、赤霄套（攻击向），走现有 set 机制。
3. **来源**：挖宝与遗府/剑冢奇遇出成品词缀装，锻造仍是自产主路。

## 五、宠物系统增强

1. **兽蛋系统**（新 type: 'egg'）：4-6 种兽蛋对应新物种；背包使用后孵化（历练 N 次 or 灵石催孵），BeastSys 新增 hatch()。
2. **新物种 4 种**：各配 SPECIES_SKILLS 专属技能。
3. **口粮分档**：兽粮（普通）/珍馐（加成），feed 走双档。
4. **进化双路径**：内丹×5 之外新增「灵果」路径（挖宝/药圃出），二选一。

## 六、技能（功法）系统增强

1. **新功法 8-10 部**：三档 × 攻/防/辅铺满，含 1-2 部带主动 skill 的战斗功法。
2. **残页参悟**：craft 新增「参悟」——功法残页 ×N 合成随机同档功法，给残页保底出口。
3. **来源**：挖宝出完整功法或残页，断碑奇遇出残页。

## 七、法宝系统增强

1. **新独名法宝 6-10 件**：accessory 位或无位祭炼型，三档分布。
2. **本命法宝祭炼升级**：新增「祭炼」——吞噬材料/多余法宝提升 z_benming bonus（上限随境界），长线养成。
3. **来源**：仙家残图为独名法宝/祭炼材料主出口。

## 八、丹药系统增强

1. **新丹药 8 种**：大还丹（大回血）、破境丹（渡劫成功率+）、凝神丹（灵力回复）、辟谷丹（省口粮）、化毒丹（解毒）、战意丹（战斗 buff）、淬体丹（永久小额+hp，稀有）、碧血丹（濒死保命，稀有）。
2. **新丹方 4-6 张**：进 ALCHEMY_RECIPES，配 m_danfang 残页研读路径。
3. **来源**：药圃/丹炉遗火奇遇出丹与方，挖宝出稀有丹。
