# 山河问剑录 2.0 开发计划

> 基于 2026-09-06 设计文档，按五层工期拆解

## 第零层 · 新核能跑（骨架）

**目标**：移动端底导航 + 五本空面板 + 光阴行动核 + 存读档，手机上新角色走几步不卡。

### 任务 0.1 · 移动端底导航框架

**做什么**：
- 在 WorldScreen.vue 底部加一排固定导航：人物 / 武学 / 行囊 / 任务 / 天地
- 每个图标点一下，弹出一本「书卷皮」面板（覆盖层，不是跳转）
- 面板左上角「收」按钮，点一下收回

**改哪里**：
- `src/components/WorldScreen.vue`：加底导航 + 五个面板组件
- `src/components/panels/CharacterPanel.vue`（新建）
- `src/components/panels/SkillsPanel.vue`（新建）
- `src/components/panels/InventoryPanel.vue`（新建）
- `src/components/panels/QuestPanel.vue`（新建）
- `src/components/panels/WorldPanel.vue`（新建）
- `src/styles/main.css`：加底导航和面板样式（移动端优先，拇指区在底部）

**验收**：
- 手机浏览器打开，底部五个图标看得见、点得着
- 点图标，面板弹出，点「收」收回
- 面板里暂时是空壳文字（「人物·待填」「武学·待填」等）

**依赖**：无
**估时**：2 小时

---

### 任务 0.2 · 光阴行动核（基础动作）

**做什么**：
- 重写 `engine/game.js` 的 `input()` 和 `advanceTime()`，支持「大段跳岁月」
- 保留旧动作：打坐、做工、休息、赶路、闲逛、吃饭、买东西
- 新增「闭关 N 年」「养伤 N 月」这类动作，一次跳多日

**改哪里**：
- `src/engine/game.js`：重写 `input()`、`advanceTime()`、`doCultivate()`、`doRest()`、`doTravel()`、`doWait()`
- 新增 `doClosedDoor(years)`、`doHeal(months)` 方法

**验收**：
- 打「闭关三年」，时间真的跳 3 年（360 日）
- 打「养伤一月」，时间跳 30 日，HP 恢复
- 旧动作（打坐、做工、休息）照常跑

**依赖**：无
**估时**：4 小时

---

### 任务 0.3 · 存读档兼容

**做什么**：
- 新内核的 state 结构变了（加了面板数据、任务日志），存读档要兼容
- 旧存档能读进来，缺的字段给默认值
- 新存档能写出去，读回来不丢

**改哪里**：
- `src/save/db.js`：加字段迁移逻辑（读旧档时补默认值）
- `src/save/port.js`：导出导入兼容

**验收**：
- 旧存档读进来，游戏能跑
- 新存档读回来，五本面板数据都在
- 导出 .shanhe.json 再导入，不丢数据

**依赖**：任务 0.1、0.2
**估时**：2 小时

## 第一层 · 一条身世局做到高潮（最要紧的一层）

**目标**：挑一个出身（老奴倾向「山村孤儿 / 身世成谜」），把这条身世局主线写全，落进任务日志牵着人走。真人盲玩 40 分钟内能被这条主线一路拽到高潮。

### 任务 1.1 · 任务日志系统

**做什么**：
- 新增 `engine/quest.js`：任务日志引擎
- 任务结构：`{ id, title, chapter, desc, goals: [{type, target, done}], rewards }`
- 任务状态：`active / completed / failed`
- 任务日志 UI：QuestPanel.vue 里列出所有任务，点一个展开详情

**改哪里**：
- `src/engine/quest.js`（新建）
- `src/engine/game.js`：加 `questLog` 字段，`input()` 里检查任务目标
- `src/components/panels/QuestPanel.vue`：任务列表 UI

**验收**：
- 打「查看任务」，弹出任务列表
- 任务目标达成（如「去后山」），任务自动标记完成
- 任务完成后，奖励发放（银钱、修为、物品）

**依赖**：任务 0.1
**估时**：4 小时

---

### 任务 1.2 · 「山村孤儿」身世局主线

**做什么**：
- 从 `content/fates.js` 里挑「山村孤儿」出身
- 写一条 5 章主线：
  1. **村中疑云**：村长被杀，留下一句「你爹娘不是病死的」
  2. **后山寻踪**：去后山找线索，撞见神秘货郎，得知「你爹是江湖人」
  3. **初入江湖**：离开村子，到天启城打听爹娘下落，撞见第一个硬仗
  4. **身世揭破**：发现爹娘是被某门派灭口，自己是被藏起来的遗孤
  5. **复仇抉择**：找上门派，是复仇还是放下？（分岔，影响后续名声和关系）

**改哪里**：
- `src/content/questlines/village_orphan.js`（新建）：主线数据
- `src/engine/game.js`：开局时根据出身加载对应主线
- `src/engine/quest.js`：支持「章节推进」「分岔选择」

**验收**：
- 选「山村孤儿」出身，开局自动接第一章任务
- 完成第一章目标（去后山），自动接第二章
- 第五章分岔选择，影响后续名声（复仇=杀孽+5，放下=善账+3）

**依赖**：任务 1.1
**估时**：8 小时（写主线数据 + 接线）

### 任务 1.3 · 主线硬仗（战斗接入）

## 验收指标

每一层结束，老奴照旧拿机器人盲玩 + 真人试玩说话——**看的不是「测试全绿」，是下面这三个数**，别又修成表面光：

1. **主线推进率**：盲玩 40 分钟内，机器人 / 真人走到第几幕？
2. **真打了几场架**：战斗核是不是真的在用？
3. **玩家感没感觉到变强**：面板里的数字 / 武学 / 装备，有没有在涨？
