# 山河问剑录 2.0 设计文档

> 状态：公子已裁定（2026-09-06）
> 来源：公子 2026-09-06 口述 + 老奴对现有 30k 行代码与桌面《a》七册图纸的审计
> 性质：玩法内核重写（乙路线）——血肉保留，心脏换新的

---

## 一、定盘星（北极星）

公子口述的江湖模样，老奴整理成五句定盘：

1. **皮是纯文字武侠**——水墨字海、打字见真章，不贴血条经验条的网游脸。
2. **里子是武侠网游**——主角有一整套能查、能养、能变强的属性 / 装备 / 技能 / 门派；头顶悬着一条这个人的专属主线；世界是咬合的——打赢的架换得来功法，结的怨会回头找你，做的选择有代价、也有回响。
3. **主角一条命，玩得好不必死**——从命帖出身入世，一路破境续命，凡人修到渡劫登顶，天地自由闯。寿元是软计时（修为跟不上才老死），不是催命符。
4. **重生是败者的退路**——只有意外横死、走火入魔、修为没跟上老死了，才走转世投胎、带一缕印记和家底、换张命帖再来。它不是日常流程，是「输了」才走的路。
5. **主线分两截**——出身给一段剧本式「身世局」（每人不同），破了这局，接上「长生登顶」的后半段主线，一路把人引向仙界、幽冥、界外那些高远去处。

## 二、保什么 / 收什么

### 保（这些是好家当，要接过来）

- **手写的世界**——五层天地里 21 城 / 90 节点 / 94 NPC 的场景正文、路网、光景。老奴读过，光景是真有鼻子有眼。
- **命帖出身这整套原材料**——16 出身、变体、命帖三件套、还有躺着的「人生节点」数据。上回没接上引擎，这回拿来做新主线引擎的地基。
- **优质手写内容**——302 桩手写奇遇、带后果带账的事件、破境 / 判词 / 印记 / 回声那些好文案、门派 / 妖兽 / 法宝 / 天材地宝的名册。这些是支线和掉落的肉。
- **修仙那副阶梯**——仙武双轨境界、寿元表、五脉旁支、幽冥轮回的全套流程、图鉴成就跨世 meta。作成长阶梯和死亡回路，正好接着用。
- **工程件**——存读档、确定性随机、懒加载、程序化音效这些，直接搬。

### 收（这些是上回把魂带偏的，得换位子）

- **698 桩生成灌水奇遇不当主食了。** 不删（是家当），但不再拿「1000 桩满编」当门面当主要喂料；先压箱底降权，等以后有新口径再逐批重写或精修。玩家眼里，宁可 30 桩各有代价的好奇遇，不要 300 桩同一句「话糙理却直」。
- **「一世一生、到寿盖棺当正餐」这套叙事改位**——寿元变软计时，主角能一直活下去，死了才转世当退路（定盘星已定）。
- **反数值红线撤了**——属性、修为、银钱回到明面，可查阅；但水墨气质保留，数字是「翻开账本看」，不是贴脸的血条经验条。
- **「玩法全靠随机泼水 + 藏在冷门节点里」这条调度**——改成任务链 + 目标驱动，随机奇遇退成路上的调味，不再当饭。

## 三、新内核八块

这一回不是把旧楼抹平重盖，是把「玩法的心脏」整个换新的，血肉（文本、世界、内容）还是原来的，通过一层「翻译」喂给新心脏。

### 1. 光阴与行动核

- 打字 / 点按钮 → 一次行动，耗半个时辰到数日不等。
- 支持「闭关数载」「养伤一月」这类大段跳岁月（上回就是缺这个，一世才被抻得望不到头）。
- 寿元当软计时挂在这儿。

### 2. 成长核

- 属性、修为、银钱回到明面；仙武双轨 + 五脉那副境界阶梯照用。
- 突破靠「机缘 + 到门槛」，突破了才续命、才开门。
- 玩家一翻面板就晓得自己几斤几两、下一层差什么。

### 3. 战斗核

- 把上回那句「能打起来的架全游戏只有一桩」的病根治了：文字回合、自由招式，输赢给数字给后果。
- 打得过就是历练和缴获，打不过真会受伤、会死——死亡接转世。

### 4. 物品·装备·武学核

- 行囊、装备槽、功法招式都可查可养可换。
- 打赢恶人得他兵刃，拜了师学得他绝学——把「打一场架 → 得一件物 → 学一式功 → 变强一截」这条网游正反馈链做出来。

### 5. 主线·任务核（这回落地的重头）

- 一套「剧本引擎」：每张命帖出身种出一条专属身世局，按章节推进、有分幕有岔路，落进任务日志让玩家随时知道「眼下该往哪使劲」。
- 破了身世局，接上长生登顶的引导，一路把人往仙界幽冥界外引。
- 支线、江湖事也走同一个日志，不再全靠随机泼水。

### 6. 恩仇·名声·世界核

- 旧账册、名声、门派关系这些保留并**看得见**。
- 谁跟你是敌、谁给你开门，都明明白白，让世界记得你这句话落到实处。

### 7. 转世·传承 meta 核

- 意外身死才走：幽冥、判词、印记、传承点、图鉴，带一点家底换张命帖再来。
- 这套旧资产流程很全，接过来当死亡后的「败者退路」，不是日常。

### 8. 呈现壳（移动优先）

- 水墨字海照旧当主舞台。
- 下头一排手机端大拇指够得着的底部导航：人物 / 武学 / 行囊 / 任务 / 天地。
- 点开是书卷皮的面板；正文、输入、按钮都按小屏排，桌面只是顺带放更大。

### 关键省力巧思：内容翻译层

旧内容（302 桩手写奇遇、事件、门派、妖兽那些）**一行不改**，新心脏只认自己的字段——中间垫一层「内容翻译」（把旧格式的选项、效果，翻成新核能认的任务 / 掉落 / 因果），这样咱们的宝贝文本直接就能喂进来，不必三万行重抄。

## 四、分层工期

公子拍板「乙路线：玩法核重写」。排了个序，先把最难验证的放在前头试水，免得盖了一大圈才发现不对味：

### 第零层 · 新核能跑（骨架）

- 移动端底导航 + 人物 / 武学 / 行囊 / 任务 / 天地五本空面板。
- 光阴行动核（打坐、做工、休息、赶路、闭关都通）。
- 存读档。

**验收**：手机上新角色走几步不卡、五本面板翻得开、存档读档不丢。

### 第一层 · 一条身世局做到高潮（最要紧的一层）

- 先从 16 出身里挑**一个最抓人的**（老奴想先做「山村孤儿 / 身世成谜」这类，天然带复仇钩子），把这条身世局主线写全：有分幕、有岔路、有躲不开的硬仗、有身世揭破的高潮，落进任务日志牵着人走。

**验收**：真人盲玩 40 分钟内能被这条主线一路拽到高潮，中途会悬心、会拍腿，不会干瞪眼不知道干嘛。**这一层验证过了，后面全是铺量；这一层没对味，改的就是一个人一个局，成本小。**

### 第二层 · 战斗与成长闭环

- 把那场硬仗真接进战斗核，从这一条线开始掉落武学、兵刃、装备，养得起来、看得见强。

**验收**：玩家走完「初出茅庐 → 学会本事 → 变强 → 打赢关键一战」，赢了有缴获、输了会受伤会怕死。

### 第三层 · 寿元压力 + 破局后接长生

- 闭关续命、寿元倒逼突破；身世局破了，登顶长生的引导线接上，把人往高境界、往世界深处引。

**验收**：会玩的玩家能一路破境活下去、望得见更上层楼；玩砸的老死走转世，转世后能感到「上一世的东西还跟着我」。

### 第四层以后 · 横向铺开

- 压箱底的手写奇遇、事件经那层「翻译」分批接成支线和路上调味。
- 再铺 1～2 个出身，验证「每人不同主线」真立得住。
- 仙界幽冥边域按登顶路接入。
- 移动手感、音效、成就、发布收尾。

## 五、验收指标

每一层结束，老奴照旧拿机器人盲玩 + 真人试玩说话——**看的不是「测试全绿」，是下面这三个数**，别又修成表面光：

1. **主线推进率**：盲玩 40 分钟内，机器人 / 真人走到第几幕？
2. **真打了几场架**：战斗核是不是真的在用？
3. **玩家感没感觉到变强**：面板里的数字 / 武学 / 装备，有没有在涨？
