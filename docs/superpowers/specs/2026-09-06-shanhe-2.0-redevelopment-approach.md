## 一、一句话总纲

**不拆楼、换心脏**：现有 30k 行里，世界/内容/文案/存档是血肉（保留），`input() → advanceTime() → 事件 → 死亡` 这条主循环是心脏（重写）。新心脏以**平行模块**长在同一个代码库里，旧内容经一层「内容翻译」喂进来，每层用盲玩机器人按三个指标验收。

## 二、现状诊断（为什么是重写而不是继续缝）

三天盲玩实测出的结构性病灶，缝补已到收益上限：

| 病灶 | 实测证据 | 结论 |
|---|---|---|
| 没有目标驱动，玩法靠随机泼水 | 36000 动作里机缘 3083 次，但主线推进为 0；念头列表=全部世界，玩家不知往哪使劲 | 必须上任务核 |
| 战斗系统形同虚设 | `effect.combat` 引擎不读（pitfalls 3.1），全场可打的架≈0 | 必须修战斗核 |
| 一世被时间拖死 | 无闭关跳岁月，1400 步才过两年；bot/玩家都走不到老死→轮回链实测 0 次 | 必须重做光阴核 |
| 成长不可见 | 修为/寿元/银钱藏在系统层，bot 玩到筑基门槛都"不知自己几斤几两" | 必须上面板 |
| 「到寿盖棺当正餐」与玩法冲突 | 寿元像倒计时催命，修为跟不上=必然挫败 | 改软计时（定盘已裁定） |

同时实测证明**血肉质量是好的**：21 城/90 节点光景有鼻子有眼、302 桩手写奇遇带后果、freshText 复读熔断、宽解析、路过事件保底——这些全部保留。

**关键纪律（从 pitfalls 固化为流程）**：
- 新内容字段先 grep 引擎消费面再写（坑 3.1 的教训写成硬门禁）；
- 每层动工前先写「断言真实形状」的测试闸；
- 幽冥/afterlife 语义与 pending 抢幕检查照搬坑册 2.6/2.7。

## 四、工程节奏（比 89h 计划多想一步的执行方案）

### 版本与分支
- 主干继续出 1.x 可玩版（当前 v25 可玩、7860 闸绿），2.0 以 **`2.0.0-alpha.N`** 系列在主干上分层落地，每层一个 alpha 里程碑；
- 理由：单人项目双分支维护成本 > 收益；分层验收本身就是回滚点。每层不达验收指标就停在该层修，不进下一层（定盘已裁定）。

### 机器人验收升级（每层的闸门，这是和 89h 计划最大的差异点）
现有盲玩机器人已验证可当验收仪器，但要看三个新指标，bot 需先升级三件套：
1. **主线推进率**：bot 读 QuestPanel 的任务列表（新选择器 `.quest-*`），量化「40 分钟走到第几幕」；
2. **真打架数**：combat 回合出现次数（见闻含战斗回文）；
3. **变强可见性**：CharacterPanel 数值两次快照差值（修为/境界/装备数）。
另需一个「引导模式 2.0」：清单从系统名改成**任务目标名**（读任务日志，往当前目标走）——这才是真玩家的行为。

### 分层执行（对齐计划书五层，标注我们的增量动作）
- **第零层（9h）**：底导航+五本空面板、光阴核（闭关/养伤）、存读档迁移。增量：先把 `input()` 的 pending 短路和 freshText 保留写进回归闸，防止重构把三天磨盘修复全冲掉。
- **第一层（18h）**：quest.js 最小版 + 「山村孤儿」五章主线 + 第三章硬仗接战斗核。增量：主线数据文件里**每一幕的选项效果字段先对照 applyEffect 消费面**写（坑册 2.2）；验收=bot 40 分钟走到第五章分岔。
- **第二层（14h）**：明数值面板、武学/行囊面板、战斗核修复+缴获链。增量：银钱下限+面板可见一并做（坑 3.3）。
- **第三层（16h）**：寿元软计时+破境透明化+长生引导线。增量：老死预警 10 年一次、破境失败给「寻访灵地」任务（坑 3.4），转世家底按开放项裁定落地。
- **第四层（32h）**：翻译层接 302 手写奇遇、再铺 2 出身（魔道余孽/皇族庶子）、仙界幽冥边域、移动手感/PWA 收尾。

## 五、开放项裁决建议（可改，但先给默认值让工程不等饭）

1. **第一个身世局**：采「山村孤儿/身世成谜」——复仇钩子最抓人，且与现有暗线（白影/货郎"像一个人"）素材天然咬合，旧 `hl_shancun_*` 三条暗线可直接并进第一、二章当岔路。
2. **698 生成批奇遇**：先压箱底，只接 302 手写批；生成批等主线验收后按「新口径逐批重写」，不回炉旧文。
3. **数字呈现**：做「档位词+数字」双轨（练气三层 · 修为 1200）——bot 验收也要靠读数字，双轨对机器人和玩家都友好。
4. **底部导航**：五本册页不加第六本，地图作为「任务」册的页签（ agree 计划书倾向）。
5. **转世家底**：全留旧资产四件（传承点/印记/图鉴/功法记忆）+ 新增「一件旧物」（从上一世装备里挑一件，保留成色与故事）——旧物是跨世叙事的钩子，成本低收益高。
