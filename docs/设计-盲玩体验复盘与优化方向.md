# 盲玩复盘：机器人五轮 2568 条记录里的玩家体验问题

> 数据来源：shanhe-bot-player 盲玩机器人五轮记录（15 / 296 / 504 / 400 / 291 步动作，共 2568 条）。机器人不读游戏代码，只看屏幕、点按钮、打大白话——它的困惑就是新玩家的困惑。

---

## 一、量化发现（按严重度排序）

### P0-① 「说走就走」全线堵死：250 次拒绝，0 次抵达
- 「你要去的方向看不见路」出现 **250 次**；出行抵达类回应 **0 次**。
- 玩家（机器人）的自由输入几乎全是探路意图：「四处走走」30 次、「出门转转」26 次、「看看四周」33 次、「找个地方歇歇脚」29 次——**没有一次真正把人带去新地方**。
- 引擎确实有 doTravel/问路系统，但自由输入解析不中，全部落进通用回声（「"去哪儿？"你被自己的话问住了」）。玩家不知道"能去哪儿"，问了又被顶回来。

### P0-② 高频动作复读严重：动作的边际反馈≈0
| 动作 | 次数 | 回应种类 | 复读率 |
|---|---|---|---|
| 打坐吐纳 | 111 | 10 | ~91% |
| 和村长聊 | 91 | 9 | ~90% |
| 去后山 | 48 | 8 | ~83% |
| 找老猎户 | 45 | 9 | ~80% |
| 练武 | 117 | 33 | ~72% |
| 逛逛 | 117 | 22 | ~81% |
| 点话头/心事 | 412 | 103 | ~75% |

打坐一次是氛围，第十次是噪音，第五十次是劝退。所有高频动作都是静态文案池，不看地点/时辰/状态。

### P1-③ 话头点了没进度感：412 次点击，「白影寻踪」5 连点原地转
- 暗线唯一推进提示是「得到后山道走一趟才有下文」，但"后山道"是哪条路、去了会怎样，玩家不可知；机器人连点 5 次，回应一字不变。
- 点话头不烧时间（21 期设计），副作用是玩家可以无限空转，游戏没有"你已查过这件事"的记忆感。

### P1-④ 时间感断裂：504 步，年龄 15→15
- 第三轮整整 504 步动作，年龄纹丝不动。玩家感知：世界是静止的、NPC 是死的。
- 根因复合：话头/心事/自由输入都不烧时间（占比最高的动作全部零成本），烧时间的动作又没有明确的"半天/一天"标注，玩家对时间毫无掌控。

### P1-⑤ 皇朝纪年倒流（实锤 bug）
- `大衍承平${30 - world.year}年`（game.js L249、L299）：世界越走纪年越小，日志实录「承平26年·冬」→「承平25年·春」。
- 任何人都没注意到，是因为所有人的注意力都在角色身上——但写在页眉的时间倒着走，武侠感杀伤力极大。

### P0-⑥ 江湖缺席：整世没有一次"武侠遭遇"
五轮合计约 1600 步在世的旅程里：
- 0 次遭遇陌生侠客 / 门派招揽 / 镖局冲突 / 赏金任务 / 比武打擂；
- 世界事件全部来自同村 NPC（村长、老猎户）与既定暗线；
- 玩家做的 60% 以上动作是打坐、练武、闲聊、闲逛——**这正是"修仙挂机模拟器"，不是自由武侠**。

### P0-⑦ 内容触达面：15 类玩法，11 类从未玩到
五轮 2568 条记录合并统计（"见闻提及"= 屏幕出现过；"主动去做"= 真操作过）：

| 玩法系统 | 见闻提及 | 主动去做 |
|---|---|---|
| 商铺买卖 | 511 | 293 |
| 名号系统 | 201 | **0** |
| 幽冥/轮回 | 0 | 8 |
| 抄录/题诗 | 0 | 3 |
| 修炼突破 | **0** | 1 |
| **拜师学艺 / 奇遇 / 行会门派 / 风水堪舆 / 古墓探穴 / 入魔心魔 / 图鉴成就 / 比武战斗 / 结义姻缘 / 置产定居** | **0** | **0** |

UI 层同样触达为零：**袖中录按钮 0 次点击、存档按钮 0 次、卷轴滚动 0 次**；983/1250 次动作全砸在话头/念头/心事上。最要命的是：**1600+ 步没有一世玩到盖棺**——"一局一生、卷末留册、下世承启"这个立项核心循环，新玩家根本走不完一遍。

### 触达面塌方的结构性原因（漏斗）
```
新手出生村野 → 只亮 5 个念头（打坐/练武/闲聊/闲逛/后山）
→ 250 次"看不见路"出不了村 → 城里内容（拜师/行会/商铺/名号）物理不可达
→ 村野没有堪舆/古墓/奇遇的触发入口 → 引擎里再厚的内容也浮不上屏幕
→ 时间感断裂、动作零成本 → 一世望不到头 → 死不了 → 轮回传承从未被体验
```
注意：机器人不点袖中录有它策略简单的因素，但五轮零点击本身就是新手引导缺失的证据——页面从未主动向玩家展示过这三卷和往世簿的价值。

## 二、优化方向讨论

### 方向 A：把「说走就走」打通（路网优先级最高）
针对 P0-①。自由武侠的第一体验是"我往哪走都行"。
1. **眼下能去哪儿**：问天/场景头永远附 3-5 个可达去处（步行可达清单），取代"看不见路"。
2. **自由输入宽解析**：含「去/走/逛/出门/转转/看看」的一律解析为"去最近的地点或列出去处"，宁可问一句「你要去后山道还是村里？」也不再回通用回声。
3. **拒绝必须带路**：「看不见路」改为三段式——先到哪、再怎么走、大约几天。永远给下一步。

### 方向 B：动作回应去重 + 状态驱动文案（反馈保鲜）
针对 P0-②。
1. **一世内复读熔断**：同一动作在同一地点的回应，同一句话一世内最多出现 2 次，超了就从"状态池"换新文案（按时辰/天气/内息等级/银钱分档）。
2. **小惊喜机制**：打坐/练武 5-10% 概率触发异动（气感、路人搭话、捡到线索），把挂机变成抽奖。
3. 数据护栏：用机器人同款脚本量复读率，上线标准"打坐复读率 < 40%"。

### 方向 C：江湖主动上门（事件密度）
针对 P0-⑥。玩家不动，世界动。
1. **路过事件**：任何动作 3-5% 概率插入随机遭遇（游侠借宿、货郎吆喝、镇上比武、镖局招人、门派弟子路过），按出身钩子定向投放。
2. **定期江湖大事**：worldEventQueue 频率提升，-quarter 级别必有一次玩家可参与的事件。
3. 遭遇要有"侠气"：给来人身份、兵刃、来意三要素，让玩家感到"江湖人就在身边走动"。

### 方向 D：时间与节奏修复
针对 P1-③④⑤。
1. **修纪年公式**：`大衍承平${base + world.year}年`，纪年只进不退（P0 顺手修）。
2. **动作时间标价**：每个动作明示「耗半日/一日」，话头空转改为消耗半个时辰且记"已琢磨过"，二次点击给差异化回应。
3. **岁末压测**：机器人脚本加"千步寿数"断言，保证正常游玩速度下 30-60 分钟能过完一世的关键节点。

### 方向 E：内容出口（让厚内容浮上屏幕）
针对 P0-⑦。引擎里 15 类玩法，玩家只摸到 2 类——不是内容不够，是内容没有"出口"。
1. **村野→城邦的引力事件**：新手村早期必然推送 1-2 个"出村诱饵"（货郎带来县城消息、过路镖师招伙计、老猎户提到山外医馆），把玩家物理送出村。村内动作出不去，一切城里内容都是死内容。
2. **按地点浮出玩法入口**：每个地点声明自己"有资格发生什么"（县城=拜师/行会/商铺/名号/比武，山野=堪舆/古墓/奇遇，村落=人情/置产），场景头下方常驻 1-2 条"此地可为之事"，玩家在新地点立刻知道新玩法存在。
3. **袖中录新手强制亮相**：开局第 3 天自动展开一次袖中录并配一句角色视角的话（"你把这三卷册子压在枕下"），往世簿在第一次问天时提一笔——让核心 UI 被动曝光。
4. **一世必达节点设计**：给每世预埋 3 个保底里程碑（如 18 岁前一次出村、一次江湖事件、一次盖棺前的判词回顾），保证"一局一生"的叙事弧在正常游玩中必然走完，轮回传承的钩子才挂得住。

## 五、v22 长跑复核（2026-09-05 23:41，run-15-38-05 仍在跑）

**背景**：机器人以 v22 构建跑长局（山村孤儿·苏云起，落铁瓦关），211 步动作 / 207 条见闻，0 页面错误 0 卡死报警。v22 修复确认生效：纪年正确（承平34年）、时间在走（秋3日→冬3日）、NPC 台词轮换不再复读。**但发现了比 v21 更隐蔽的盲区——路在屏幕上，但折叠了。**

### P0-⑦ 出城按钮被折叠：211 步 0 次出行
- tw_guanqiang（关墙戍楼）念头共 11 条，UI 折叠上限 8（WorldScreen `HUATOU_LIMIT=8`，`slice(0,8)`）；
- 被折叠的 3 条是：和老兵聊 / 问老兵些事 / **去昆吾**——出城按钮排在列表最末，永远藏在「…还有别的念头（3 条）」后面；
- 机器人只在「一个念头都没有」时才展开折叠区（bot.mjs L323-324）→ 8 个可见念头轮着点就永远饿不死 → **211 步没出过关**；
- v22 的「出行可见」只修到引擎层（按钮确实生成了），没修到 UI 层（生成但不可见）。教训：**可见性必须以"首屏可见"为准，不是"存在于 DOM"。**

### P0-⑧ 问天引导 3 次全落空：机器人从没点过问天
- 游戏在 unclear 回声里三次明示「想不起要做什么，就点一下『问天』」；
- bot 的问天触发条件是「连续 N 步无新见闻」——但 NPC 台词四句轮换、每步文本都变，卡死检测永远不触发；
- 结果：新手最需要的兜底引导，被"文案在动"骗过了。**轮换文案救了复读率，骗了卡死检测。**

### P1-⑥ 「跟路过的人搭句话」解析落空
- 实测 `parse('跟路过的人搭句话')` → verdict: miss（六句高频新手话术里唯一 miss 的一句）；
- 落空后进 unclear 池，机器人拿到「这话你说了半截」类回声，学习不到任何东西。

### P1-⑦ 关隘节点事件密度不足：白灾要等冬
- tw_guanqiang 内容 = 8 念头 + 2 NPC 各 4 句台词 + 1 个季节事件（白灾，冬季才触发）；
- 秋季 200 步里零事件（「眼下的事」只出现过 5 次且全在开局）——v22 的路过事件在铁瓦关一次没触发过（打坐 6%/闲逛 12% 的概率池可能不含 frontier 标签节点，或 rolls 太少）；
- 诺言「白灾守关」反复被戍将台词提及，但没有任何可推进接口（问进度 → 仍给台词轮换）。

### 优化方向 F（新增）
1. **E-5 出行为王**：`去X` 类念头永不折叠、置顶显示（出行是破磨盘的唯一钥匙，必须首屏可见）；折叠徽标注明「含出行」；或把折叠按钮放最前。
2. **bot 升级**：念头选择加"类别轮换"——出行类 / 问天 / 展开折叠区，每类封顶 N 步必轮到一次；FREEFORM 剔除 miss 句「跟路过的人搭句话」（待引擎补规则后再加回）。
3. **引擎补规则**：搭话/路过 → 按 node.npcs 或 passby 随机给一段遭遇（复用二十二期路过事件池）。
4. **节点事件密度**：frontier/town 类节点补"日常小事件池"（换防、商队入关、烽火误报、马市开集、流民过关），保底每 15-20 步一事件；核查路过事件概率池是否覆盖 frontier 标签。
5. **诺言可问进度**：doTalk 话题命中 active 誓约 key 时返回进度态而非通用台词。
6. **回归指标新增**：出行按钮曝光率（首屏可见率）、问天点击率、每 50 步事件数。
