## 一、修 A：问天接线（bug 修复）

- `case 'help'` → `doAskHeaven()`：把 `askHeaven()` 四段（处境/眼下的路/修行/光阴）拼成一条 system 文字入卷轴，**不烧时间**（指路不是行动）。
- 「眼下的路」取话头前 6 条；若暗线未结，第一行加「心里搁着一桩事：${hl.title}」。
- 旧占位响应（generic echo）保留给真正的无意图输入（见 D）。

## 二、修 B：核心话头常驻

- `sceneHuotou()` 在**节点话头之前**固定插入两条（若该节点话头里没有同类）：
  - `打坐吐纳`（命中 cultivate 意图）
  - `练武`（别名→练功，命中 practice 意图）
- 措辞约束：话头文案必须以意图正则的锚头开头（^打坐/^练），否则解析不到——**话头标签逐个过 parse 校验**（闸断言）。

## 三、修 C：暗线接入话头（钩子→动作的翻译层）

- `sceneHuotou()` 在暗线未结时插入一条 `想想「${hl.title}」`。
- 新意图 `ponder`：结算为指路式文字——念一遍 hint + 读 `EVENTS[hl.hook].nodes` 翻译成「该去 ${节点名} 走一趟」+ 若 hook 事件已入 doneEvents 则改口「这桩心事已了」。烧 1 时辰（想心事也是光阴，但这是有产出的）。
- 眼下栏（修 F）的心事 chip 点击即发这句话头。

## 四、修 D：miss 不烧时间 + 一句引导

- `doEcho('unclear'/'generic')` 不再 `advanceTime(1)`——没听懂就不该扣光阴。
- generic 回声末尾追加固定引导：「（想不起要做什么，就点一下「问天」。）」

## 五、修 E：话头折叠

- WorldScreen 话头扶手默认显示前 **8** 条，超出部分折叠进「…还有别的念头（N 条）」展开钮（纯 UI，引擎不动）。

## 六、修 F：眼下栏（常驻锚点）

- 顶栏下新增一行「眼下」：暗线 chip（「心事·白影寻踪」，点击发 ponder 话头；暗线已结则显示「心头无事」）+ 境界词（反数值：只给词不给数）。
- 已在 time 串里的岁数/年号不重复。

## 七、修 G：文卷层级

- main.css：`.jm-system/.jm-imprint/.jm-dead` 加左侧墨线 + 微深底；`.jm-ambient` 降低透明度。让「任务级」和「天气级」一眼可分。

## 八、修 H：存档按钮措辞

- `存入slot1` → `存入·档一`，`读slot1` → `读·档一（名字）`；backup-preimport 显示名「导入前的旧进度」已在导出侧处理，读档列表过滤不显示备份档（防误读）。

## 九、修 I（审计新增）：暗线大面积断线——32/35 条死暗线补全

实现修 C 时审计发现的**内容级 bug**，且是修 C 的前置依赖：

- 35 条此生暗线（HIDDEN_LINES）里，只有 3 条山村线在 events.js 里有落地事件；魔道/皇族两条线虽然写好了接引奇遇（adv_canpian_name/adv_pixiang_ying），但其 entry 用了 `via`/`needFlag` 字段——**引擎的 checkAdventures 根本不读这两个字段**，奇遇永远不可达。其余 30 条线的 hook 事件（ev_jiancu_zhui 等）**从未被定义**。
- 结果：绝大多数玩家开局被告知「你心里搁着一桩事」，然后这桩事永远没有下文——这是体验层面最大的空头支票。

**修法**（src/content/hiddenLineEvents.js，一次性补齐 32 条）：
1. **30 条自足式 hook 事件**：id 与 HIDDEN_LINES.hook 一致；nodes=出身命帖的 startNode（原乡原点，开局即可撞见）；weight 5、minAge 16、cond.flags=[暗线 id]；每条手写 2-3 句正文 + 两个选项（小事掂量：一点修为/心性/银钱层面的余味，不抢奇遇的戏）。
2. **2 条桥接式**（魔道残篇/皇族披香）：hook 事件正文收在「引子」上，选项一 `trigger` 接通已写好的接引奇遇（adv_canpian_name/adv_pixiang_ying）——死而复生，内容零浪费。
3. `doneEvents` 语义：fireEvent 自动记账（已核实），ponder 的「这桩心事已了」判定成立。
4. 闸断言：35 条 hook 全部能在事件总表解析到；每条 hook 事件 nodes 非空、options≥2、cond.flags 对准暗线 id。

## 十、验收（闸二十一）

1. `问天` 出四段指路（含话头清单与暗线行），不烧时间。
2. 任意节点话头含 `打坐吐纳`/`练武` 且逐条 parse 命中意图（话头标签 100% 可解析）。
3. 有暗线角色话头含 `想想「…」`，ponder 结算指向 hook 节点名；hook 已结则改口。
4. miss 分支光阴不流动 + 引导语在场。
5. **35 条暗线 hook 全部在事件总表可解析**（修 I），桥接两条的 trigger 能拉起接引奇遇。
6. 眼下栏 chip 文案/境界词渲染正确（组件级断言经引擎数据侧验证）。
7. 全链路回归：新角色 10 步内零异常，闸一~二十全绿。
