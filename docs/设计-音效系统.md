# 设计文档 · 音效系统（二十期 B 卷）

> 状态：**定稿即实现口径**。

## 一、目标与美学立场

这游戏的美学是「意头」：不报数值、不摆面板，一切用文字光景说话。音效必须服从同一哲学：

- **程序化合成，零音频素材**。不引一个 mp3/ogg——打包体积是十五期刚从 3.67MB 压到 1.53MB 挣来的，不能让几个音效文件败光。WebAudio 振荡器+噪声+包络，几行代码一个音色。
- **稀疏，不聒噪**。音效是文卷的落款印章，不是背景音乐。全游戏没有循环 BGM（v1 不做，见 §六），只有事件落点的短音。
- **可整个关掉**，且关掉是显式的、持久的。不玩任何「音量不能全关」的把戏。

## 二、架构（零引擎侵入）

**引擎层（game.js 及全部 content/engine 模块）不 import 音频。** 理由：闸测在 node 下 headless 跑，引擎引 WebAudio 等于把闸测烧了；且「文卷说什么」和「声音怎么配」是两个变化方向。

接线点全在 UI 层（main.js store）：

```
src/audio.js
  ensureCtx()        // 惰性 AudioContext，首次用户手势时建（浏览器autoplay政策）
  sfx.play(name)     // 查 SOUNDS[name] 定义 → 合成；muted 或无 ctx 则静默返回
  SOUNDS             // 音色定义表（名 → 合成函数描述）
  KIND_TO_SFX        // 文卷 kind → 音色名 映射表
  muted / setMuted() // localStorage('shanhe.audio.muted') 持久化；node/隐私模式静默降级
```

### 文卷事件 → 音色映射（watch store.journalTick 的增量尾条）

| 文卷 kind / 事件                   | 音色名           | 合成思路                                |
| ------------------------------ | ------------- | ----------------------------------- |
| dialog / echo                  | `tick`        | 木鱼感：短三角波 660Hz，60ms 衰减              |
| ambient                        | `hush`        | 极轻正弦 220Hz，120ms，音量最低（岁月脚步声）        |
| adventure（奇遇开卷）                | `bell_low`    | 494Hz+988Hz 双正弦，1.2s 指数衰减，庙里低钟      |
| combat（进战）                     | `drum`        | 噪声突发 + 80Hz 正弦，80ms，闷鼓              |
| combat 胜（journal 含「胜」尾段）       | `gong_up`     | 523→784 两音上行，各 180ms                |
| combat 败                       | `fall`        | 330→220 下滑音，300ms                   |
| event（事件幕起）                    | `bell_mid`    | 587Hz 单正弦 0.8s                      |
| imprint / dead                 | `gong_deep`   | 98Hz 正弦 + 微失谐 98.7Hz 拍频，2s 长衰减，幽冥深处 |
| 善/喜 落账（尾条含「善」）                 | `bell_bright` | 1046Hz 清铃 0.5s                      |
| 按钮 click（全局 .btn/.mini-btn 委托） | `tick`        | 同上，更轻                               |

映射规则实现在 `pickSfx(lastEntries)`：优先看尾条 kind，特殊文本（善账/胜/败）优先于 kind 兜底。**表驱动**：KIND_TO_SFX 里没有的 kind 静默不出声——宁可少响，不可乱响。

## 三、静音开关

- `store.audioMuted`，UI 开关放两处：标题屏页脚（「声 · 开/声 · 关」文字钮，符合反数值美学，不放喇叭图标）+ WorldScreen 工具行 mini 钮。
- 持久化 localStorage；读写全部 try/catch（隐私模式/node 下降级为「不响不炸」）。
- AudioContext 惰性创建：首次 play 且从未创建时 `new AudioContext()`，若 state==='suspended' 则 resume——都在用户手势调用链内，合规。

## 四、错误与边界

- 无 AudioContext（老浏览器/node import）：所有函数提前返回，不抛。
- SOUNDS 定义缺名：play 里查不到即 return，不炸。
- 连发节流：同名音色 80ms 内重复触发只响一次（combat 连击刷屏时保护耳朵）。

## 五、验收标准

1. 全部音色定义可枚举、有合成参数描述（闸审计：映射表里引用的每个名字都在 SOUNDS 里有定义）。
2. muted 状态 localStorage 往返一致；node 下 import 不炸。
3. 引擎层 grep 无 audio 引用（架构红线，闸守住）。
4. 人耳验收：公子在预览里点开听——音效美学最终由耳朵裁决。

## 六、v1 明确不做（留给公子裁定后再开）

- 循环 BGM / 环境底噪（雨声、虫鸣）：需要噪声源管理与淡入淡出，价值密度低。
- 音量分级：只有「响/不响」两档——意头美学不接受音量条。
- 每个奇遇独立音效：奇遇千桩，不可能也不必要。
