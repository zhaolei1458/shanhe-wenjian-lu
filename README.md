# 山河问剑录

一款纯手写文本的武侠·仙侠「文字模拟人生」游戏。无数值面板，打字即江湖。

## 玩法

输入自然语言驱动一切：**去**、**打坐**、**干活**、**拜师**、**捕捉**、**炼器**、**袖中录**……  
出生抽命帖（来处/软肋/钩子），活一辈子（行走/际遇/结仇/证道），死后入幽冥（望乡台/十殿审账/孟婆汤/轮回井），带传承投下一世。

## 运行

```bash
npm install
npm run dev       # 开发
npm run build     # 构建
npm test          # 十二道闸测试（7563 项）
npx vite preview --port 4173
```

## v15.0 存读档完整性与包体瘦身（十五期·工程加固）

- **修复真 bug：读档丢整世文字**。本世卷轴（journal）此前挂在实例上而不进 state——读档后文字全清空；挂起事件（pending）、岁末大事队列（worldEventQueue）、界面幕别同样不落档，事件中途存读档会断链。现 persist() 将四者写入 state._journal/_pending(JSON 快照，含不可序列化物宁可不挂)/_worldQueue/_uiMode，构造器读档时恢复。
- **奇遇大池懒加载**：九期生成批（adventures15~24，约 700 桩 2.2MB）从静态 import 改为 `loadBigPools()` 动态加载——boot 灌池 + claimFate 幂等闸兜底（多快点进投生也不会带残池进世）；未加载时小池照常可玩。构建主 chunk 3.67MB→1.53MB（-58%），大池拆 10 个按需 chunk。
- **确定性续档校验**：同种子下「不读档继续跑」与「存档→读档后跑」十步逐字一致——RNG 快照续档是逐位精确的，不是近似。
